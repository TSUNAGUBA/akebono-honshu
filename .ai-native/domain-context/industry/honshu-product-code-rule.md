# 品番（SKU）コード変換ルール

> **出典:** ヒアリング資料「ホンシュ_品番設定 コード一覧.xlsx」（3シート構成）および既存システム「品番台帳入力」画面のスクリーンショット観察
> **最終更新:** Phase 0 ヒアリング時点
> **状態:** 一部未確認事項あり（後述）

---

## 1. 概要

本システムにおける品番は、各マスタの `品番コード（item_conversion_code）` を機械的に連結して **自動生成** される。
品番の生成ロジックは業務ルールそのものを表現しており、商品マスタ設計の中核を成す。

色違い・サイズ違いは **別品番（SKU レベル）** として管理される。
すなわち、1 つの「商品企画」に対して「色数 × サイズ数」分の品番レコードが存在する。

---

## 2. 品番の全体構造（11桁固定）

```
 [1桁] [1桁] [1桁] [3桁]    [1桁] [2桁] [2桁]
   A     D     2    0 0 1     N    0 0    0 0
  年式  型式  季節  品番連番  工場 カラー サイズ
```

| 桁位置 | 桁数 | 項目 | 参照マスタ／コード表 |
|--------|------|------|----------------------|
| 1 | 1 | 年式 | §3.1 |
| 2 | 1 | 型式（商品タイプ） | §3.2 |
| 3 | 1 | 季節 | §3.3 |
| 4-6 | 3 | 品番連番（4桁目はサブ分類、5-6桁は連番） | §3.4 |
| 7 | 1 | 工場 | §3.5 |
| 8-9 | 2 | カラー | §3.6 |
| 10-11 | 2 | サイズ | §3.7 |

**読み取り例:** `FA2071F11` + 末尾2桁
- F = 年式（要確認: 2016 or 2026）
- A = 型式（吊込W底）
- 2 = 季節（春夏）
- 071 = 品番連番
- F = 工場（藤東）
- 11 = カラー（ピンク）
- 末尾2桁 = サイズ

## 3. 各桁のコード表

### 3.1 年式（1桁目）

西暦下1桁との対応。「2011年」メモあり（要確認: A が指す基準年）。

| コード | 西暦1桁 | コード | 西暦1桁 |
|--------|---------|--------|---------|
| A | 1 | G | 7 |
| B | 2 | H | 8 |
| C | 3 | I | 使用不可 |
| D | 4 | J | 9 |
| E | 5 | K | 0 |
| F | 6 | | |

**特殊コード:**
- `N` = 定番（年式に紐付かない継続商品）
- `Z` = 統合

**注意:** `I` は数字の `1` と紛らわしいため使用不可。

### 3.3 季節（3桁目）

| コード値 | 意味 |
|---------|------|
| 1, 6, 7, 8, 9 | 通年 |
| 2, 4 | 春夏 |
| 3, 5 | 秋冬 |
| 0 | その他 |

**注意:** 同じ意味に複数のコードが割り当てられている（例: 通年=1/6/7/8/9）。なぜ複数値があるのかは要確認（推測: 商品ライン別の通年区分？）。

### 3.4 品番連番（4-6桁目）

3桁で 000〜999 の連番。ただし **4桁目はサブ分類** として意味を持つ模様（「スリッパ 一般」シートに以下の対応表あり）:

| 4桁目 | 分類 |
|------|------|
| 0, 1, 2, 3, 4 | レギュラー |
| 5, 6 | メンズ |
| 7, 8 | ジュニア |

**要確認:** この 4桁目サブ分類が全商品タイプ共通か、スリッパ一般のみか。

### 3.6 カラー（8-9桁目）

色マスタの「色番表示」を 2 桁ゼロパディングで使用。色マスタは内部コード（3桁、000-099 以上）と表示コード（2桁、00-99）の 2 系統を持つ。

**色の分類体系:**
- `000-009`: アソート系（標準, 2, 3, 4, 5, 値札 1-5）
- `010-019`: 赤系（レッド, ピンク, ワイン, 赤系-, 赤系+, 赤系 値札 1-5）
- `020-029`: 緑系（グリーン, ライト・グリーン, ダーク・グリーン, 緑系-, 緑系+, 緑系 値札 1-5）
- `030-039`: 青系（同様の構造）
- `040-049`: 茶系（ブラウン, ライト・ブラウン, ダーク・ブラウン, 茶系-, 茶系+, 茶系 値札 1-5）
- `050-059`: 紫系
- `060-069`: 白系（ホワイト, アイボリー, ベージュ, 白系-, 白系+, 白系 値札 1-5）
- `070-079`: 黄系（イエロー, ライト・イエロー, ダーク・イエロー, オレンジ, 黄系-, 黄系+, 黄系 値札 1-5）
- `080-089`: 灰系（グレー, ライト・グレー, ダーク・グレー, 灰系-, 灰系+, 灰系 値札 1-5）
- `090-099`: 黒系（ブラック, ゴールド, シルバー, 黒系-, 黒系+, 黒系 値札 1-5）

**要確認（業務概念）:**
- 「値札 1〜5」とは何か？（→ 現場ヒアリング待ち）
- 「赤系-」「赤系+」の `-/+` は何を意味するか？（→ 現場ヒアリング待ち）

### 3.7 サイズ（10-11桁目）

靴サイズ・アパレルサイズ・ホームウェア寸法が **同一マスタに同居**。表示は 2 文字（cm 値の小数点も省略）。

**カテゴリ別:**
- フリー: `00`
- アパレルサイズ: `SS`, `S`, `M`, `L`, `LL`, `3L`, `4L`
- アソート: `AS`
- 子供（cm）: `110c`, `120c`, `130c`, `140c`, `150c`, `160c`
- 靴サイズ（12.0cm〜28.5cm を 0.5cm 刻み）: `12.0`, `12.5`, ..., `28.0`, `28.5`

## 4. 文字使用制約

| 桁 | 使用不可 | 理由 |
|----|----------|------|
| 1桁目（年式） | I | 数字の 1 と混同 |
| 7桁目（工場） | I, O | 数字の 1, 0 と混同 |

## 7. 設計上の含意（Phase 1 以降への申し送り）

- 品番生成は **マスタ選択 → コード連結 → 一意性チェック → 確定** のフロー。重複時は連番（4-6桁目）で回避する設計が必要
- 商品の親概念（企画）と SKU（品番）の 2 層構造になる可能性あり。画面の「企画番号」「商品分類」がその親概念候補
- 色 × サイズの組み合わせで品番が増殖するため、マスタ画面 UI では「色 × サイズの表形式一括登録」が業務効率上必須
