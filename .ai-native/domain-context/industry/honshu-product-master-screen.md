# 商品マスタ画面（既存システム「品番台帳入力」）構造観察

> **出典:** ヒアリング時に提供された既存システム「品番台帳入力」画面のスクリーンショット
> **目的:** リプレース対象の現行画面を構造化し、新システム設計時の参照情報とする
> **最終更新:** Phase 0 ヒアリング時点
> **状態:** 観察ベース（一部推測あり・要確認事項あり）

---

## 1. 画面の位置づけ

- **画面名:** 品番台帳入力
- **役割:** 商品マスタ（11桁の品番）を登録・修正・参照するための中核画面
- **業務上の意味:** 各マスタ（17 マスタ + 工場マスタ + 甲皮素材マスタ）の選択を組み合わせて 1 件の品番レコードを生成・編集する
- **モード:** 区分ドロップダウンで `1新規 / 2修正 / 3参照` を切替

## 3. 価格項目（**17 マスタ仕様には未記載の新規発見**）

3 層の価格管理が組み込まれている。

| 項目 | 用途（推測） |
|------|-------------|
| 正価額 | 定価（メーカー希望小売価格相当） |
| 小売価額 | 実際の小売価格 |
| 納品先価額 | 卸価格（納品先=取引先別） |
| 仮値段 | 仮登録段階の価格 |
| 仮値段対象 | `1小売価格 / 2納品価格` を切替 |
| 換算率 | 多通貨換算用 |
| プラント費 | （要確認） |

**多通貨対応:** 画面に `CNY / US / CN` の列があり、`22.7, 101, 21.4` 等の数値が並ぶ。為替レートに基づいた多通貨価格表示と推測。中国外注品の原価管理に直結。

| キー | 機能 | MVP 要否（推測） |
|------|------|------------------|
| F1 | コード検索 | 必須（マスタ検索） |

## 7. 商品マスタ画面の動線（推測）

```
[新規 / 既存品番参照]
       ↓
[マスタ選択（商品タイプ, 季節, 工場, 素材, ブランド, 機能 ...）]
       ↓
[仮品番が表示される]
       ↓
[色・サイズの組み合わせを登録]
       ↓
[F9 サイズ展開 → 色×サイズ分の品番レコードを一括生成]
       ↓
[価格設定（正価・小売・納品先）]
       ↓
[F10 登録 → 品番マスタ確定]
```

## 8. 商品マスタの推定スキーマ（Phase 1 への申し送り）

### 親テーブル候補（商品企画レベル）

「商品分類」「企画番号」が、品番（SKU）の上位概念として存在する可能性が高い。
1 つの商品企画から、色 × サイズの組み合わせで複数の品番レコードを生成する 1:N 構造。

| カラム名（仮） | 由来 |
|---------------|------|
| 商品分類 / 企画番号 | 画面項目 |
| 商品名 | 画面項目 |
| 商品名2 | 画面項目 |
| 商品タイプ | マスタ参照 |
| 商品季節 / 管理季節 | マスタ参照 |
| 機能 | マスタ参照 |
| ブランド | マスタ参照 |
| 甲皮素材 / 中底素材 / 底素材 | マスタ参照 |
| 正価額 / 小売価額 / 納品先価額 | 画面項目 |
| 工場 | マスタ参照 |
| 仕入先 | マスタ参照 |

### 子テーブル候補（SKU レベル = 11桁品番）

| カラム名（仮） | 由来 |
|---------------|------|
| 品番 (PK, 11桁) | 自動生成 |
| 親商品ID | FK |
| 色 | マスタ参照 |
| サイズ | マスタ参照 |
| 仕入単価 | グリッドから |
| 税率 | グリッドから |

→ Phase 1 でテーブル定義 SoT を作成する際の出発点。
