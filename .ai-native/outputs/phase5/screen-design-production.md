## 2. 画面ごとの機能定義

### 2.1 商品詳細「素材構成(BOM)」タブ（B-01）
- 既存 `products/families/[id].vue` にタブ追加（明細／画像／**素材構成(BOM)**）。
- レイアウト: 行＝部位（甲皮/中底/底/付属/副資材のセクション分け）、列＝素材(Combobox)・所要量(数値)・単位(Select)・推奨仕入先(Combobox)・ロス率(%)・備考・削除。
- 既存3部位（甲皮/中底/底）は初期表示、所要量未設定は警告色ハイライト。「行追加」で付属・副資材を追加。
- 保存＝`PUT /products/families/{id}/materials`（**差分upsert・単一Tx**）。3部位（甲皮/中底/底）はBOM未登録時に既存3FK代表素材から**初期シード**表示（保存は product_materials のみ、3FKへ書戻さない＝疎結合、監査M-3）。
- バリデーション: 所要量>0、同一部位×素材重複（インライン表示、BOM-001/BOM-002）。

### 2.2 `/production/instructions`（一覧、PI-02）
- 共通一覧レイアウト（タイトル＋件数＋検索＋ビュー切替トグル）。**デフォルト=テーブル**（発注一覧と同方針、情報密度重視）。
- テーブル列: 指示番号 / 品番(9桁) / 品名 / 加工先 / 生産数量 / 希望納期 / **ステータスバッジ**(下書き/指示済/完了/中止) / **出力バッジ**(未出力/出力済 YYYY-MM-DD) / 最終更新者・日。
- カードビュー: ヘッダ帯（ステータス＋出力バッジ＋指示番号）、タイトル（品名＋納期）、サブ（加工先＋生産数量）、サムネ（品番代表画像、既存P-06流用）。
- フィルタ: ステータス / 加工先 / 納期範囲 / 期間。フリーワード（指示番号・品番・品名・加工先）。
- 行クリック→詳細。ヘッダ「+ 新規生産指示」。

### 2.3 `/production/instructions/new`（新規、PI-01）
- **起点:** 直接開いて品番検索（SKU直接入力/商品一覧から選択）。※旧起点 (a) 商品詳細「生産指示を作成」リンク（`?from_family={id}`）は 2026-07 改修で商品詳細の「次のアクション」セクションごと除外（クエリパラメータ `familyId` 自体は互換のため引き続き受け付ける）。
- ヘッダ: 加工先(Combobox、suppliers)・希望納期(DatePicker)・連絡文章(テキストエリア、テンプレ複写ボタン)。
- 明細: **色×サイズマトリクス**（既存 O-02/F-14 のマトリクスダイアログを再利用）。存在するSKUのみ入力可、存在しない組合せは disabled。各セルに生産数量を入力。合計＝生産総数を自動集計表示（プログレス的に視認）。
- 登録＝`POST /production-instructions`（Draft）→詳細へ。バリデーション PINST-001/002/003 をインライン。

### 2.4 `/production/instructions/[id]`（詳細・編集・発行・Excel、PI-03/PI-04）
- ヘッダ: 指示番号・ステータスバッジ・出力バッジ・加工先・品番・生産数量・納期。
- タブ「明細」（色×サイズ別数量、編集はDraft/Issuedのみ）、タブ「連絡文章」。
- アクションボタン（権限・状態で活性制御）:
  - 「編集」（Draft/Issued）、「**発行（指示確定）**」（Draft→Issued、確認ダイアログ「発行すると生産指示=済になります」）、「生産完了」（Issued→Completed）、「中止」（理由入力ダイアログ）、「**Excel出力（生産指示書）**」（いつでも、初回時に凍結の旨を注記）。
  - 「**この指示から素材発注を作成**」→ `/production/material-orders/new?from_pi={id}`（主動線②へ）。
- Excel: Blob ダウンロード（既存 a タグ download 方式、Content-Disposition 抽出）。

### 2.5 `/production/material-orders/new`（新規＝BOM展開、MO-01）
- **起点:** 生産指示詳細から `?from_pi={id}`（推奨）または品番＋数量直接指定。
- Step 1（展開）: `POST /material-orders/prepare` の結果を表示。**推奨仕入先別にグルーピングされた素材リスト**（素材名・部位・推奨数量・単位）。各グループが1発注書候補。
- Step 2（調整）: 仕入先別タブで、数量・単価・納期を確認・手調整（端数/ロット）。素材単価は機密（`price:write` 保有時のみ編集可、デフォルトマスク表示、`MaterialPrice.View` 監査）。**単価未設定明細を含む発注書は合計に「単価未設定あり」注記**（subtotal は 0 扱い、data Mi-2）。
- 登録: 仕入先ごとに「この仕入先の発注書を作成」→`POST /material-orders`（仕入先別に逐次POST、各独立Tx）。BOM未登録時は MORD-001 でBOM登録へ誘導。

### 2.6 `/production/material-orders/[id]`（詳細・発注確定・Excel、MO-03/MO-04）
- ヘッダ: 発注番号・素材仕入先・ステータス・出力バッジ・由来生産指示リンク・納期。
- タブ「明細」（素材・数量・単位・単価(マスク/権限)・由来品番）。
- アクション: 「編集」（Draft）、「**発注確定**」（Draft→Ordered、「確定すると素材発注=済」）、「中止」、「**Excel出力（素材発注書）**」。

### 2.7 生産手配 未/済 一覧（PS-01）
> **採用案（オペレーター確定「品番ごと2軸バッジ」）:** 既存 `/products` 商品一覧に**生産手配バッジ列を統合**し、専用 `/production/status` も同一コンポーネントで提供（フィルタ初期値が異なるだけ）。重複実装を避ける（CLAUDE.md 原則3）。
- 商品一覧（`/products?include=production_status`）の各品番行/カードに **2バッジ**（色＋テキスト＋アイコン、WCAG 1.4.1）:
  - 「素材発注 未/済」（未=灰、済=緑）
  - 「生産指示 未/済」（未=灰、済=緑）
- **BOM未登録の品番**は「BOM未登録（手配前）」を**第3状態**として別表示し、「手配漏れ（手配可なのに未）」と区別（移行直後は既存全品番がBOM未登録のため誤誘導を防ぐ。監査CR Minor-1/SA Minor-2）。
- **権限（監査Major-2）:** 生産バッジは `purchase_order:read` 保有時のみ表示（非保有ユーザには生産列を出さない＝情報非対称回避）。「未」バッジからの作成導線は `purchase_order:write` 保有時のみ活性（非保有は `aria-disabled`＋理由ツールチップ、403を未然防止）。
- フィルタ: 「素材発注=未」「生産指示=未」「BOM未登録」のトグル（手配漏れ/BOM未整備の抽出）。
- 「未」バッジクリック→該当作成画面（生産指示=未なら `instructions/new?from_family`、素材発注=未なら生産指示確認後 `material-orders/new`、BOM未登録なら商品詳細BOMタブ）。
- `/production/status` はこの一覧をデフォルト「いずれか未」フィルタで開く入口。

## 6. 全データフロー I/F 検証（画面→API）

| シナリオ | 画面遷移 | API |
|---|---|---|
| BOM登録 | 商品詳細→BOMタブ→保存 | `PUT /products/families/{id}/materials` |
| 生産指示 | 商品詳細→生産指示new→明細→登録→発行→Excel | `POST /production-instructions`→`/issue`→`/excel` |
| 素材発注 | 生産指示詳細→素材発注new(prepare)→仕入先別登録→発注確定→Excel | `/material-orders/prepare`→`POST /material-orders`→`/order`→`/excel` |
| 未/済確認 | 商品一覧（バッジ＋フィルタ） | `GET /products?include=production_status&filter[...]` |

→ 既存 architecture.md §4 のデータフロー検証方式（ドキュメントトレース）と整合。全画面が既存API設計と1:1で接続、I/F矛盾なし。
