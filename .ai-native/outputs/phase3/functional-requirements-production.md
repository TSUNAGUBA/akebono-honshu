## 2. 機能別 入出力定義

### 2.1 BOM（B-NN）

#### B-01: 素材構成（BOM）登録・編集
| 観点 | 内容 |
|------|------|
| 入力 | 品番(product_family_id)、各行: 部位(甲皮/中底/底/付属/副資材), 素材(material_id), 1足あたり所要量, 単位, 推奨仕入先(任意), ロス率(任意), 備考 |
| 処理 | `product_materials` upsert。部位0/1/2の代表素材を `product_families` 3FK列へ同期（SoT先行→cache）。重複(部位×素材)チェック |
| 出力 | 保存通知、BOM一覧再表示 |
| 業務ルール | 同一部位に複数素材可。所要量>0。論理削除のみ |
| エラー | PROD-101(所要量・単位不正), PROD-102(部位×素材重複) |
| 権限 | 品番台帳管理権限 ≥ 更新可能 |

#### B-02: BOM所要量展開プレビュー
| 観点 | 内容 |
|------|------|
| 入力 | 品番(or 生産指示id), 生産数量（色×サイズ別 or 合計） |
| 処理 | Σ(所要量 × 数量 × (1+ロス率)) を素材別に集計。推奨仕入先別にグルーピング |
| 出力 | 素材別・仕入先別の推奨発注数量リスト（素材発注作成のプリセット） |
| 業務ルール | BOM未登録時は PROD-105 |
| 性能 | 1品番のBOM展開 300ms 以内 |

### 2.2 生産指示（PI-NN）

#### PI-01: 生産指示書 新規作成
| 観点 | 内容 |
|------|------|
| 入力 | 品番, 加工先(factory_supplier_id), 希望納期, 色×サイズ別生産数量, 連絡文章 |
| 処理 | `production_instructions`(status=Draft)＋`production_instruction_lines` 生成、`instruction_no`(YY-PI-NNNNN)採番。planned_quantity＝明細合計を整合チェック |
| 出力 | 生産指示書プレビュー、詳細画面へ |
| 業務ルール | 数量>0、同一SKU重複不可 |
| エラー | PROD-103(数量0), PROD-104(SKU重複), PROD-107(品番にSKU未展開) |
| 権限 | 発注情報管理権限=あり（要オペレーター確認、§4） |

#### PI-02: 生産指示書 一覧・検索
| 観点 | 内容 |
|------|------|
| 入力 | フリーワード(指示番号/品番/品名/加工先)、絞込(status, 加工先, 納期範囲, 期間)、ソート、ビュー(表/カード) |
| 処理 | `production_instructions` 検索（加工先・品番を Include、N+1回避） |
| 出力 | 一覧（指示番号, 品番, 品名, 加工先, 生産数量, 納期, ステータスバッジ, 出力バッジ） |
| 性能 | 一覧初期表示 500ms（既存NFR §1.1）|

#### PI-03: 生産指示書 編集・発行・完了・中止
| 観点 | 内容 |
|------|------|
| 入力 | 指示id, 編集値 / 発行 / 完了 / 中止(理由) |
| 処理 | status遷移: Draft→Issued(`instructed_at` SET)→Completed(`completed_at` SET) / →Cancelled。Draft/Issued のみ編集可 |
| 出力 | 更新通知、ステータスバッジ更新 |
| 業務ルール | 発行で品番の「生産指示=済」。中止は物理削除しない。Excel出力は中止後も可 |
| エラー | PROD-108(中止済の編集不可) |

#### PI-04: 生産指示書 Excel出力
| 観点 | 内容 |
|------|------|
| 入力 | 指示id |
| 処理 | ClosedXMLでテンプレ流し込み。初回出力時のみ加工先名/コード/品番のスナップショット凍結＋`first_exported_at` SET、毎回`last_exported_at`更新＋export_log相当(audit) |
| 出力 | 生産指示書 Excel（ダウンロード） |
| 業務ルール | テンプレは新規設計（既存帳票無し）。実帳票入手後に体裁調整（§ヒアリング#6） |
| 性能 | 1指示(50明細)5秒以内（既存NFR §1.1） |
| エラー | PROD-109(テンプレ/生成失敗) |

### 2.3 素材発注（MO-NN）

#### MO-01: 素材発注書 新規作成（BOM展開→仕入先別）
| 観点 | 内容 |
|------|------|
| 入力 | 起点の生産指示id（or 品番＋数量直接指定）、調整後の素材別数量・単価・納期、素材仕入先 |
| 処理 | B-02で展開した所要量を初期値に、素材仕入先別に `material_orders`(status=Draft)＋`material_order_lines` 生成、`order_no`(YY-MO-NNNNN)採番。各明細に由来品番(`product_family_id`)保持 |
| 出力 | 素材発注書プレビュー（仕入先別に複数生成され得る）、詳細画面へ |
| 業務ルール | BOM未登録は PROD-105。数量>0、単価≥0 |
| エラー | PROD-105(BOM未登録), PROD-106(数量/単価不正) |
| 権限 | 発注情報管理権限=あり（要確認） |

#### MO-02: 素材発注書 一覧・検索
| 観点 | 内容 |
|------|------|
| 入力 | フリーワード(発注番号/素材仕入先/素材名)、絞込(status, 素材仕入先, 納期, 由来品番, 期間)、ソート、ビュー |
| 処理 | `material_orders` 検索（素材仕入先 Include） |
| 出力 | 一覧（発注番号, 素材仕入先, 明細素材数, 合計金額(マスク), 納期, ステータス, 出力バッジ） |

#### MO-03: 素材発注書 編集・発注確定・中止
| 観点 | 内容 |
|------|------|
| 入力 | 発注id, 編集値 / 発注確定 / 中止(理由) |
| 処理 | status遷移: Draft→Ordered(`instructed_at` SET)/→Cancelled。Draftのみ全編集、Orderedは限定編集 |
| 出力 | 更新通知 |
| 業務ルール | 発注確定で品番の「素材発注=済」。中止は物理削除しない |

#### MO-04: 素材発注書 Excel出力
| 観点 | 内容 |
|------|------|
| 入力 | 発注id |
| 処理 | ClosedXML流し込み。初回出力時に仕入先名/コードのスナップショット凍結＋`first_exported_at` |
| 出力 | 素材発注書 Excel |
| 業務ルール | 既存 O-06 と同方式。素材単価は機密扱い |
| 性能 | 5秒以内 |

### 2.4 生産手配ステータス（PS-NN）

#### PS-01: 品番ごと未/済 2軸バッジ一覧・フィルタ
| 観点 | 内容 |
|------|------|
| 入力 | 既存商品一覧（P-04）への列追加 or 専用「生産手配」一覧。フィルタ(素材発注 未/済, 生産指示 未/済) |
| 処理 | 品番ごとに **派生算出**（§data-design §7.2 のEXISTS、部分インデックス利用）。一覧クエリにサブクエリ2本を結合（N+1回避、SQLで完結） |
| 出力 | 各品番行に「素材発注: 未/済」「生産指示: 未/済」バッジ。フィルタで未手配のみ抽出 |
| 業務ルール | 済判定: 生産指示=Issued以上の指示が存在 / 素材発注=Ordered の発注明細が当該品番に存在 |
| 性能 | 一覧（2,000品番）500ms（既存NFR §1.1）。部分インデックスで担保 |
| 遷移 | 未バッジクリック→該当作成画面（PI-01/MO-01）へ |

## 3. 業務ルール（増分 BR）

| # | ルール | 適用 |
|---|--------|------|
| BR-P1 | BOMは品番(product_family)単位。1足あたり所要量＋単位を持つ | B-01 |
| BR-P2 | 3部位代表素材(既存3FK)はBOMのcache。SoT=product_materials、編集時に同期 | B-01 |
| BR-P3 | 生産指示は品番×生産1回単位。色×サイズ別数量を明細で持つ | PI-01 |
| BR-P4 | 素材発注数量(推奨)= Σ所要量×生産数量×(1+ロス率)、手調整可 | MO-01 |
| BR-P5 | 素材発注は素材仕入先別にヘッダ、明細に由来品番を保持 | MO-01 |
| BR-P6 | 未/済は品番ごと派生算出（生産指示=Issued以上、素材発注=Ordered） | PS-01 |
| BR-P7 | 採番: 生産指示=YY-PI-NNNNN、素材発注=YY-MO-NNNNN | PI-01/MO-01 |
| BR-P8 | 生産指示・素材発注とも論理削除＋中止状態（既存発注と同方針）。Excel出力は中止後も可 | PI-03/MO-03 |
| BR-P9 | 帳票宛名は初回Excel出力時にスナップショット凍結（既存F-22と同方針） | PI-04/MO-04 |
| BR-P10 | 監査ログ: BOM/生産指示/素材発注の C/U/D＋Excel出力＋素材単価閲覧 | C-03拡張 |

## 4. ユーザー権限（既存4権限の適用拡張）

| 機能 | 適用権限 | 備考 |
|------|---------|------|
| B-01/B-02（BOM） | 品番台帳管理権限 ≥ 更新可能 | BOMは品番属性の延長 |
| PI-01〜04（生産指示） | **発注情報管理権限=あり**（暫定） | 既存「発注情報管理権限」を生産系に割当。**要オペレーター確認**: 工程実績管理権限の活用も選択肢（既存はDB保持/UI非表示） |
| MO-01〜04（素材発注） | **発注情報管理権限=あり**（暫定） | 同上 |
| PS-01（未済一覧） | 品番台帳/発注情報のいずれか参照可 | 閲覧系 |

> **確認事項 D-prod-7:** 生産系を既存「発注情報管理権限(あり/なし)」に割り当てるか、UI非表示の「工程実績管理権限」を活用するか。**推奨:** 発注情報管理権限を割当（既にUI露出済・2値で十分）。工程実績管理権限は次段階「工程実績」で活用。
