## UC-PROD-1: 商品の素材構成（BOM）を登録する

| 項目 | 内容 |
|------|------|
| ID | UC-PROD-1 |
| 名称 | BOM（素材構成・所要量）登録 |
| 主アクター | 生産管理オペレータ |
| 位置づけ | 生産指示・素材発注の前提。商品マスタ登録（UC-1/既存P-01）の延長または商品詳細から実施 |
| 頻度 | 品番登録時／素材構成変更時 |

**前提条件:** 対象品番（product_family）が登録済み。素材（甲皮/中底/底＋付属/副資材）が `materials` マスタに存在。

**メインフロー:**
| # | アクター操作 | システム応答 |
|---|------------|-------------|
| 1 | 商品詳細画面で「素材構成（BOM）」タブを開く | 既存3部位素材（甲皮/中底/底）を3FK代表素材から**初期シード**表示（保存対象外）。所要量未設定はハイライト |
| 2 | 各部位の素材・**1足あたり所要量・単位**を入力（例: 甲皮 ポリエステル 0.30 ㎡） | 行ごとに受付。同一部位に複数素材（表地+裏地）も追加可 |
| 3 | 付属（面ファスナー・中敷等）・副資材（値札・証紙・箱）の行を追加し素材・所要量・単位を入力 | 受付 |
| 4 | 各素材の推奨仕入先・ロス率（任意）を設定 | 受付 |
| 5 | 「保存」 | `product_materials` に**差分upsert保存（単一Tx）**。3FK列へは**書き戻さない**（疎結合、監査M-3。3FKは表示用・初期シード元のみ） |

**例外フロー:**
- EF-1（所要量0以下・不正単位）: バリデーションエラー（BOM-001）
- EF-2（同一部位・同一素材の重複）: エラー（BOM-002）

**事後条件:** 品番にBOMが紐づき、生産数量を掛けて素材所要量を算出可能になる。

**システム化 vs 外:** システム化=BOM入力・所要量保持（product_materials の差分upsert、3FKへは書き戻さない）。外=歩留り・所要量の実値判断（現場知識）。

## UC-PROD-2: 生産指示書（加工指図書）を作成・出力する

| 項目 | 内容 |
|------|------|
| ID | UC-PROD-2 |
| 名称 | 生産指示書作成・Excel出力 |
| 主アクター | 生産管理オペレータ |
| 位置づけ | **本案件の主動線①**。商品マスタ＋生産数量を起点に工場へ生産を指示 |
| 頻度 | 都度（生産を起こすたび） |

**前提条件:** 対象品番にSKU（色×サイズ）が展開済み。加工先（工場）が `suppliers` に存在。

**メインフロー:**
| # | アクター操作 | システム応答 |
|---|------------|-------------|
| 1 | 「生産指示」→「新規」、または商品詳細から「生産指示を作成」 | 品番選択済み（商品詳細起点時）。生産指示作成画面表示 |
| 2 | 加工先（工場）・希望納期を選択 | 受付 |
| 3 | 色×サイズマトリクスで生産数量を入力（既存 O-02 のマトリクスUI流用） | 合計＝生産総数を自動集計表示 |
| 4 | 連絡文章を入力（テンプレート複写可） | 受付 |
| 5 | 「登録」 | `production_instructions`＋`production_instruction_lines` 生成、生産指示番号（26-PI-NNNNN）採番、status=Draft |
| 6 | 「発行（指示確定）」 | status=Issued、`instructed_at` SET。**この品番の「生産指示」が済バッジに** |
| 7 | 「Excel出力（生産指示書）」 | 加工先名・品番を凍結（初回時）し生産指示書 Excel を生成・ダウンロード |

**代替フロー:**
- AF-1（修正）: status=Draft/Issued は編集可。Excel再出力は何度でも可（既存 O-06 と同方針）
- AF-2（中止）: status=Cancelled（物理削除しない）

**例外フロー:**
- EF-1（生産数量0）: PINST-001
- EF-2（同一SKU重複）: PINST-002

**事後条件:** 生産指示書がDBに保存・Excel出力され、品番の生産指示ステータスが済。素材発注の起点となる。

**システム化 vs 外:** システム化=指示作成・採番・Excel出力・ステータス更新。外=工場への送付（メール等）・生産可否の合意。

## UC-PROD-3: 素材の発注書（生地材料発注）を作成・出力する

| 項目 | 内容 |
|------|------|
| ID | UC-PROD-3 |
| 名称 | 素材発注書作成・Excel出力 |
| 主アクター | 生産管理オペレータ |
| 位置づけ | **本案件の主動線②**。生産に必要な素材を素材仕入先へ発注 |
| 頻度 | 生産指示に伴い都度 |

**前提条件:** 起点となる生産指示書が存在（または品番＋数量を直接指定）。対象品番にBOMが登録済み（UC-PROD-1）。

**メインフロー:**
| # | アクター操作 | システム応答 |
|---|------------|-------------|
| 1 | 生産指示詳細から「素材発注を作成」 | **BOM×生産数量で所要量を自動展開**。素材ごとに推奨数量（所要量×数量×(1+ロス率)）・推奨仕入先をプリセット表示 |
| 2 | 素材仕入先ごとにグルーピング（推奨仕入先別に発注書を分割） | 仕入先別の素材発注書（複数）を提案表示 |
| 3 | 数量・単価・納期を確認・調整（端数・ロット調整は手入力上書き可） | 受付 |
| 4 | 「登録」（仕入先ごと） | `material_orders`＋`material_order_lines` 生成、素材発注番号（26-MO-NNNNN）採番、由来品番を `product_family_id` に保持 |
| 5 | 「発注確定」 | status=Ordered、`instructed_at` SET。**この品番の「素材発注」が済バッジに** |
| 6 | 「Excel出力（素材発注書）」 | 仕入先名を凍結（初回時）し素材発注書 Excel を生成・ダウンロード |

**代替フロー:**
- AF-1（指示なし単独発注）: 品番＋数量を直接指定して素材発注も可（`production_instruction_id`=NULL）
- AF-2（修正/中止）: 既存発注と同方針

**例外フロー:**
- EF-1（BOM未登録）: 所要量展開不可エラー（MORD-001）＋BOM登録への誘導
- EF-2（数量0・単価負）: MORD-002

**事後条件:** 素材発注書がDBに保存・Excel出力され、品番の素材発注ステータスが済。

**システム化 vs 外:** システム化=BOM展開・仕入先別グルーピング・採番・Excel出力。外=素材仕入先への送付・価格交渉。

## UC-PROD-4: 品番ごとの未/済ステータスを一覧で確認する

| 項目 | 内容 |
|------|------|
| ID | UC-PROD-4 |
| 名称 | 生産手配 未/済 一覧 |
| 主アクター | 生産管理オペレータ |
| 位置づけ | **本案件の主動線③**。手配漏れ防止 |
| 頻度 | 日次（朝の手配確認） |

**メインフロー:**
| # | アクター操作 | システム応答 |
|---|------------|-------------|
| 1 | 商品一覧（または専用「生産手配」一覧）を開く | 品番ごとに「**素材発注 未/済**」「**生産指示 未/済**」の2軸バッジを表示 |
| 2 | フィルタ「素材発注=未」「生産指示=未」等で絞り込み | 未手配の品番のみ表示（手配漏れの可視化） |
| 3 | 未の品番を選択 | 商品詳細／生産指示作成／素材発注作成へ遷移 |

**事後条件:** 未手配品番が一目で分かり、UC-PROD-2/3 へ動線。

**システム化 vs 外:** システム化=未/済の派生算出・バッジ表示・フィルタ。外=手配優先度の判断。
