## ~~T-1: Reka UI ショートカット衝突マトリクス (F-21 対応)~~ **不要化 (2026-05-19)**

> **Phase 6 で F-21 廃止判断確定:** 既存システムの F-key (F9 サイズ展開 / F10 登録 / F12 閉じる) 互換は採用せず、全操作を **画面上のボタンで提供** する方針に確定。
>
> **採用理由:**
> - ブラウザ予約キー (F11 フルスクリーン / F12 DevTools / F5 リロード等) との衝突回避
> - アクセシビリティ向上 (キーボード操作に不慣れなユーザにもボタンで明示)
> - モバイル/タブレット対応 (F-key はモバイルキーボードに存在しない)
> - 新人ユーザの学習コスト削減 (画面ボタンは見れば分かる)
> - Reka UI 標準キーバインドとの干渉なし (Esc/Tab/Enter/矢印キー等は Reka UI 標準のまま採用)
>
> **影響範囲:** Phase 5 screen-design.md §3.4 サイズ展開アクション + §5.4 キーボードショートカット方針 に反映済。`useKeyboard` composable 実装も不要。Reka UI / Radix UI / WAI-ARIA 公式ドキュメントの衝突調査も不要。

## T-2: 国内用 Excel テンプレートサンプル調達 (H-3 / F-12 対応)

### 目的

Phase 6 で確定した発注書 Excel 出力機能 (O-06、MVP は ① 国内用テンプレートのみ) の実装に必要な、既存システムから出力した **① 国内用 発注書 Excel サンプル** を調達する。

### なぜ必要か (業務的根拠)

仕入先 (取引先) は既存システムの発注書を見慣れており、**新システムでも全く同じ見た目** であることが業務的に重要 (Phase 6 オペレーター確認、2026-05-19):

- 仕入先側のファイリング・処理フロー・印刷レイアウトが既存帳票に最適化済
- 新システム導入は社内事情、仕入先には影響を与えないのが原則
- フォント / 列幅 / 印刷範囲 / 改ページ / 罫線 / セル結合 / 会社ロゴ等の暗黙仕様を再現する必要あり

サンプルなしで実装すると以下のリスク:

| リスク | 影響 |
|---|---|
| 暗黙仕様の見落とし (フォント種類、罫線太さ等) | 完成後に業務担当者から「違う」と差し戻し |
| 試行錯誤の手戻り | 修正 3-5 回繰り返す Iteration 工数増 |
| 印刷時の崩れ発覚 | 画面 OK でも印刷で改ページずれ等 |
| 仕入先からのクレーム | リリース後の問合せ対応コスト |

### 期限

**Phase 7 Iteration 1 開始日の 1 週間前まで** (独立監査指摘 2026-05-19)

### 担当

**オペレーター** (調達責任者)

### 受領状況 (2026-05-19 時点)

オペレーターから **サンプル発注書 3 種類の画像 3 枚** を提供可能との確認あり (3 種類 = ① 国内用 / ② 海外用 / ③ 海外用+管理表)。MVP は ① 国内用のみ実装のため、優先度は ① 国内用画像。

### 画像 vs .xlsx ファイル: 両方の利点と限界

| 形式 | 利点 | 限界 |
|---|---|---|
| **画像 (.png/.jpg)** | 見た目が一目で分かる、機密マスキングが容易、メール添付しやすい | セル位置・列幅・印刷範囲・数式の **正確な数値が読み取れない**、ピクセル測定での近似値しか得られない |
| **.xlsx ファイル** | フォント・列幅・印刷範囲・数式・セル結合の **正確な値が取得可能**、ClosedXML テンプレートに直接転用可 | 機密情報のマスキング作業が必要、ファイル共有手段の調整必要 |

### Phase 7 実装戦略 (画像 3 枚を受領した場合)

**Step A: 画像受領で着手可能な範囲 (MVP 暫定設計)**
- 画像から全体レイアウト・列構成・配置を読み取り、ClosedXML テンプレートを **暫定作成**
- フォントは類似フォント (MS ゴシック等) で代用、列幅はピクセル測定からの近似値
- Phase 7 Iteration 1 で実装プロトタイプを作成、業務担当者と画面で照合

**Step B: 完全再現に向けた .xlsx 取得 (推奨、Phase 7 後期)**
- 画像で大筋を作った後、業務担当者から **元の .xlsx ファイル 1 枚** を取得 (機密マスキング後)
- ClosedXML テンプレートを .xlsx から再生成、フォント・列幅・印刷範囲の正確な値を反映
- 最終検収前に印刷物で既存と同等かを確認
