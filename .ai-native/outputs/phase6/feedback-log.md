## 1. 仮想ペルソナ定義

> **注意:** 実ユーザヒアリングは未実施（Phase 0 ペルソナドキュメント §4「実ユーザ調査未実施」が継続）。本セクションは Phase 2 業務フロー記述・Phase 0 スポンサー発言・既存システム画面観察から構築した **推測ペルソナ**。Post-Phase6 で実担当者と照合・補正する。

### 1.1 P-OP: 生産管理部 オペレータ（メインユーザ）

| 属性 | 値 |
|---|---|
| 役割 | 商品マスタ登録・発注書作成・出力（UC-1, UC-2, UC-3 のメインアクター）|
| 経験 | OEM 業務 5-15 年想定、業務知識深い |
| IT スキル | Excel ヘビーユーザ、ショートカット (F-key) 多用、Web 業務システムは「使えるが好きではない」想定 |
| 業務環境 | 業務 LAN PC、Chrome / Edge、デスクトップ（マウス + キーボード）|
| 一日のリズム | 朝: 取引先からの依頼受領 → 午前中に商品マスタ登録 + 発注書作成 → 午後: 工場とのやり取り + 改訂対応 |
| 推測ペインポイント | (a) 3システム間の二重入力で時間消耗（Phase 1 確定）, (b) F-key ベース操作に慣れていて Web UI のクリック多用に違和感, (c) 大量の入力フィールドに対する誤入力恐怖, (d) Excel テンプレートのレイアウト崩れ過去経験 |

| 警戒ポイント | 既存 F-key 運用からの変化（F9 サイズ展開, F10 登録, F12 閉じる 等）、印刷帳票（Excel 出力）の体裁変化 |
